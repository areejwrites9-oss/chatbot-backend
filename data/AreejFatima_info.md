## Example notes

Areej is learning how to build a RAG chatbot from scratch. The project has a Python backend, a React frontend, and a Qdrant collection that stores vector embeddings.

The backend loads Markdown files from the `data/` folder, splits them into chunks, creates embeddings, and stores the vectors in Qdrant. When a user asks a question, the backend turns the question into an embedding, searches for the most relevant chunks, and sends that retrieved context to Gemini.

## Example Q&A

- Question: What technologies are used in this project?
  Answer: The backend uses Python, FastAPI, Qdrant, and the Gemini API. The frontend uses React and Tailwind CSS.

- Question: What is RAG?
  Answer: RAG stands for Retrieval-Augmented Generation. It combines a search step with a generation step so the model can answer using relevant knowledge from a local dataset.

- Question: Where is the knowledge stored?
  Answer: The knowledge is stored in Markdown files in the backend `data/` directory and indexed in Qdrant after ingestion.
